# Backlot icon provenance

These SVG paths are direct, mechanically separated copies of the inline icons in
`HTML/Backlot for UE5.dc.html`, the frozen parity source supplied with this plugin. `currentColor`
and fixed gray strokes were normalized to white so Slate can apply the source state color through
brush tinting without changing path geometry, view boxes, stroke widths, joins, or corner radii.

The Backlot diamond remains a native rotated Slate square because the reference diamond is CSS
geometry rather than an inline SVG. No third-party icon library is used.
